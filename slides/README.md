# Hashu slides

Three-slide [Slidev](https://sli.dev) deck introducing Hashu: what it is, how minting and hashrate redemption work, and the Testnet4 prototype status.

```bash
cd slides
npm install
npm run dev      # present at http://localhost:3030
npm run build    # static site in dist/
npm run export   # PDF (needs playwright-chromium)
```

Speaker notes live in the `<!-- -->` comments under each slide.
