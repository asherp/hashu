# Redeem at Foundry USA

**Probably not a fit.** Foundry USA is an institutional pool: accounts go
through onboarding (KYC) and it is aimed at large operations
**(unverified: current sign-up and minimum hashrate terms)**. If you
already have a Foundry account, the shape is the usual one.

| Field | Value |
|---|---|
| Pool URL | `stratum+tcp://btc.foundryusapool.com:3333` **(unverified)** |
| Worker name | `<your account>.hashu` **(unverified format)** |
| Worker password | `x` |

Foundry's connection details are in its customer portal, so take them from
there rather than from this page. Make sure the URL is
`stratum+tcp://` or `stratum+ssl://` with a port.

## Check it arrived

Look for the `hashu` worker in the Foundry dashboard.

Hashu's privacy pitch (buy with any sats or USDT, earn fresh coins at your
pool) is weakest here, since a KYC'd pool account ties the payout to you.
